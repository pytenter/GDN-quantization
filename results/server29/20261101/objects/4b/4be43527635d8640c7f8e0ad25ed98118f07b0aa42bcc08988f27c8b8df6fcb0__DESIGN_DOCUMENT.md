# QWEN_GDN Stage-B Full60 mechanism capture design

## 1. Scope and scientific target

This is a design-only closure. It does not start Full60, load the model, invoke
the scorer, generate tokens, or modify the model, quantizer, rotations, metric
definitions, or reducer semantics.

The target chain is:

`rotation -> quantization distortion -> recurrent state drift -> trajectory instability -> output degradation -> reasoning failure`.

Frozen endpoint context is FP 52/60, Native INT8 18/60, Hadamard 41/60,
C5 33/60, and C6 36/60. Correctness remains an endpoint label; it must never
be used to select tokens, layers, metrics, or checkpoints.

## 2. Existing Stage-B inventory

The frozen V3 reducer consumes 4,096 groups for each of 24 GDN layers and four
INT8 conditions (`Native`, `Hadamard`, `C5`, `C6`) at every token. It already
provides:

- float64 moments for `scale`, `papr_linear`, `qdq_relative_l2`, `absmax`, and
  `range`;
- exact integer multiplicative-histogram counts per layer and globally;
- per-token p99, CVaR99, and max for `scale`, `papr_linear`, and
  `qdq_relative_l2`, accumulated into per-layer summaries;
- deterministic Top-42 ledgers, including value, token, and group identity;
- deterministic Top-32 as the first 32 records of the same Top-42 total order;
- exact paired scale-ratio threshold counts;
- atomic per-sample state/checkpoint/manifest behavior.

It does not currently provide:

- sample correctness, output length, final token, or output-token divergence;
- absolute L2, maximum, or mean-absolute quantization error;
- a per-token/per-layer scalar trajectory table;
- persistent recurrent FP-versus-INT8 state drift;
- drift increments or post-divergence stability;
- logit KL, margin degradation, delta NLL, or top-1 changes.

The P1 accelerator changes only exact histogram insertion and deterministic
TopK candidate extraction. Its 64-token canonical states are byte-identical to
the V3 oracle, so it is the required reducer implementation for a future run.

## 3. Two semantically distinct capture planes

The experiment must not conflate immediate quantization error with recurrent
error accumulation.

### Plane A: controlled common-FP capture

At every token and layer, all four INT8 conditions receive the same FP state.
The unchanged formal rotation and `quantize_c128` paths produce quantizer-space
inputs and QDQ states. QDQ branch states are discarded after observation.

This plane identifies the direct rotation-to-distortion link and feeds the
unchanged accelerated V3 reducer. A read-only sidecar receives tensors already
present in the formal path and writes four canonical-basis scalar errors:

- `state_l2_error = ||recover(QDQ(R(S_fp))) - S_fp||_2`;
- `relative_error = state_l2_error / max(||S_fp||_2, eps)`;
- `max_error = max(abs(recover(QDQ(R(S_fp))) - S_fp))`;
- `mean_absolute_error = mean(abs(recover(QDQ(R(S_fp))) - S_fp))`.

`recover` must be the existing formal rotation recovery method. No rotation or
quantizer formula may be copied into the capture code. Tail suppression is
measured separately in quantizer coordinates through the existing reducer's
scale/PAPR/QDQ-relative-error p99, CVaR99, max, Top-32, and Top-42 outputs.

### Plane B: recurrent persistent-writeback capture

This plane uses an FP branch and persistent INT8 branches. Each INT8 branch
reads its own prior dequantized state on the next token. State comparisons are
made only after formal recovery into the canonical FP coordinate system.

To stay within 24 GiB RTX 3090 memory, execute two fixed bundles sequentially:

1. `FP + Native INT8 + Hadamard`;
2. `FP + C5 + C6`.

The repeated FP branch must have identical token, state, and logit hashes across
the two bundles before their outputs can be joined. A five-row bundle is
forbidden because the prior three-row replay already reached 22,113 MiB.

For condition `c`, layer `l`, token `t`, save:

- `drift_l2[t,l,c] = ||S_fp[t,l] - recover(S_c[t,l])||_2`;
- `drift_relative[t,l,c] = drift_l2 / max(||S_fp[t,l]||_2, eps)`;
- `drift_increment[t,l,c] = drift_l2[t,l,c] - drift_l2[t-1,l,c]`.

The signed change in drift magnitude is deliberately used for the minimal
design. It needs only the previous scalar, not a retained full error tensor.
Non-finite values are evidence: record first onset and counts; never censor,
retry, or silently replace them.

## 4. Frozen token basis and divergence semantics

The paired mechanism replay uses the existing 1,854,451 FP continuation-token
sequence, preserving identical sample, seed, and token order across conditions.
This is the only basis on which per-token condition comparisons are paired.

Separately, reuse the already frozen generation artifacts for FP, Native,
Hadamard, C5, and C6. For each sample-condition pair:

- `first_divergence_token` is the first zero-based generated-token index whose
  token id differs from FP; if one sequence is an exact prefix, divergence is
  the first missing index; it is null only for exact equality;
- `generated_length` and `final_token` come from the frozen output payload;
- `correctness` comes from the existing Frozen V4 result;
- no generation and no scoring are performed during capture.

Post-divergence trajectory metrics are explicitly labelled counterfactual:
after the observed output divergence index, the replay continues on the FP
teacher-token path. This supports stability analysis but is not claimed to be
the condition's free-running state trajectory.

## 5. Function-space signals

Reduce logits online; never save vocabulary-sized logits.

For every replay token and INT8 condition, save:

- `kl_fp_to_condition = sum(p_fp * (log_p_fp - log_p_condition))`;
- `top1_margin_degradation`: FP top1-minus-top2 margin minus the condition
  margin evaluated on the same two FP token identities;
- `delta_nll`: condition NLL minus FP NLL for the next frozen FP token;
- `top1_changed`: whether the condition top1 differs from FP top1.

The last token has no causal next-token target and must have `delta_nll = null`,
not a duplicated self-target.

## 6. Artifact schema

All large tables use typed Parquet with Zstandard compression, atomic temporary
files, SHA256 sidecars, and readback before `.done` creation. Partition by
`shard/sample_id/condition`; within each partition rows are ordered by
`token_idx, layer_id`.

### `sample_metadata.jsonl`

One row per sample-condition: sample id, problem id, seed, condition,
correctness, generated length, first divergence token, final token, finish
reason, output hash, scorer hash, and frozen-input hash.

### `controlled_quantization/*.parquet`

`token_idx:int32`, `layer_id:uint8`, and four `float32` distortion fields.

### `recurrent_trajectory/*.parquet`

`token_idx:int32`, `layer_id:uint8`, `drift_l2:float32`,
`drift_relative:float32`, and `drift_increment:float32`.

### `function_space/*.parquet`

One row per token-condition: token index, three float32 function metrics,
`top1_changed`, FP margin, and finite-status flags.

### `reducer/`

Unchanged V3/P1 per-sample artifacts, including exact histograms, tail moments,
paired counts, and deterministic Top-42 ledgers. Top-32 is materialized only as
a verified prefix view and never recomputed with another ordering.

### `analysis/`

- per-layer state/drift mean, relative mean, p99, CVaR99, max, and finite counts;
- layer rankings with a frozen primary ranking key (median across samples of
  per-sample CVaR99 drift), deterministic layer-id tie break;
- post-divergence stability: drift slope, median absolute drift increment,
  runaway-threshold crossings, finite fraction, and top1-change fraction;
- paired endpoint groups: same-correct, same-wrong, rescue, and regress for each
  INT8 condition versus FP and versus Hadamard;
- correlations are descriptive and must report sample counts and uncertainty.

## 7. Minimality

No recurrent state tensor or full logit tensor is written to disk. Only the
current chunk, branch cache, current error tensor, and scalar reductions exist
in memory. Drift increment stores a scalar difference rather than a previous
full error tensor. Layer tail statistics are derived from the saved scalar
trajectory and existing reducer output instead of duplicating group tensors.

This is the minimum design that can connect every link in the requested chain
while preserving the formal model paths and reducer semantics.
