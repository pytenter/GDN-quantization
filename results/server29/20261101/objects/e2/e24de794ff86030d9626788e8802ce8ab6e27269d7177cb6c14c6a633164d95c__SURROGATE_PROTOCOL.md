# LING KDA short-horizon surrogate protocol

Status: **FROZEN BEFORE PROXY/LABEL JOIN**. This is discovery analysis; the historical outcomes were already known and no prospective-confirmation claim is made.

## Scope and units

The natural-rotation roster is frozen to the 16 identities in `frozen_config.json`. The primary data are `pg19-test-37702` and `pg19-test-5396`. Calibration starts are 256 and 1024, both before the earliest 2048 anchor. The two starts are aggregated by an arithmetic mean. The primary aggregation is an equal mean over the 18 captured KDA layers, all 16 heads and all value dimensions; layer 20 is auxiliary only.

Each branch is a real teacher-forced recurrent forward with INT8 R128 QDQ and physical-coordinate writeback after every token. FP and quantized branches use the same token prefix. Rotation is applied before QDQ and inverted before persistent writeback. No long-horizon state, canonical scalar norm, archived 32K trace, or future query enters P1/P2/P3.

## Alignment and metrics

At token `t`, the recurrent update is executed first. FP state is reconstructed from the exact captured FP KDA records. The quantized branch is then QDQ-written back. State/readout metrics compare the resulting post-update, post-QDQ branch state to FP state and use the normalized FP query from token `t`. The functional KL emitted at token `t` is necessarily measured before the current token's writeback, so it reflects all persistent QDQ through `t-1`; this one-step semantic distinction is retained rather than hidden.

- B0: post-QDQ state MSE at the start token.
- P1: mean square of the true K3 contraction `E @ (q_FP / ||q_FP|| / sqrt(128))` at the start token.
- P2_W128: `E_t` contracted with the second moment of normalized FP queries from `[t-128,t)`. No query at or after `t` is used.
- P3_H32/P3_H128: mean P1-form readout energy over the actual persistent-QDQ rollout.
- B1_H32/B1_H128: mean state MSE over the same horizons.
- B2_H32/B2_H128: mean `KL(FP logits || branch logits)` over the same teacher-forced horizons.
- B3: historical JPROP and POR, joined only after proxy-score freeze and used only as retrospective references.

## Ranking analysis and fixed interpretation rules

One panel is one document × one historical anchor × the frozen 16 rotations. Report Spearman rho, pairwise concordance (ties excluded), rank reversals and residual rank association after JPROP. Primary and Secondary panels from a document are robustness targets, not independent documents.

A candidate is called stable only if rho is positive in all four panels. It has incremental value only if it beats each named cheaper baseline in both rho and concordance in at least three panels and has positive residual rank association after JPROP in at least three panels. P2 is preferred over P3 if it matches or exceeds P3 in rho and concordance in at least three panels and is materially cheaper. Windows, signs, layers and aggregation will not be retuned after outcome inspection.

Natural magnitude-matched contrasts are a diagnostic: all pairs whose relative B0 gap is at most 10% are enumerated, with no outcome-based pair selection. If these do not provide clear directional discrimination, the report records `NATURAL_DIRECTIONAL_DISCRIMINATION = INSUFFICIENT`.
