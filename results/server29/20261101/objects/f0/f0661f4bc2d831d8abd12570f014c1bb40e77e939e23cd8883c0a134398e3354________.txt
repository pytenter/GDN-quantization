遇到以下情况必须 STOP：

- 正式 preregistration 或必需身份资产无法验证。
- 原冻结100/20/22/58输入资格无法复现。
- 16 rotation roster 或 scorer 身份发生不合格变化。
- 40篇内不能取得4个 eligible documents。
- selection freeze 不完整。
- deterministic / numerical / observer / resume gate 失败。
- 实际显存或磁盘不足。
- 模型运行被不可合法恢复的错误中断。
- FP reference 或 student KL 不完整、不有限、位置不匹配。
- 任何科学协议需要未授权修改才能继续。

STOP后必须保存失败位置、已有合格资产和后续 `NOT_RUN` 状态。

不得生成看似完成的空科学 CSV，不得用零填充失败结果。

## 12. 最终回报格式

完成或 STOP 后，逐项明确回答：

1. 本次读取了哪些正式 pre-registration 和成功 manifest？SHA 是否验证通过？
2. PG19 100→58输入资格是否完全复现？
3. 实际短程筛选多少篇？是否在最多40篇内找到四篇？
4. 最终选择哪四篇文档？
5. 每篇 P1 与 L7 分别选择什么 rotation？双方 midrank gap 是多少？
6. Selection freeze 是否在任何32K outcome 前完成？
7. numerical、observer、fresh-process resume、persistent QDQ 和 physical gates 是否全部通过？
8. 4个FP与8个student是否全部完成？
9. 四篇的完整精度 `K_P1 / K_L7 / Delta` 分别是多少？
10. P1 胜、L7 胜、tie/unresolved 各多少？
11. 是否得到具有方向性的独立前瞻证据？哪些结论不能宣称？
12. 是否发现与旧 MIXED / Posthoc cross panel 相同的候选选择现象？
13. 本次实际 GPU worker 总数、真实 GPUh、峰值 CUDA allocated/reserved/NVML 是多少？
14. 最终 source commit、SHA、manifest 和绝对交付目录是什么？
15. 是否严格 STOP，确认没有启动梯度训练、新 L8/L9 或 AIME？

最后输出机器可读取状态，例如：

- `PREREGISTRATION_IDENTITY_STATUS`
- `INPUT_ELIGIBILITY_STATUS`
- `SHORT_HORIZON_SELECTION_STATUS`
- `FROZEN_SELECTION_STATUS`
- `NUMERICAL_QUALIFICATION_STATUS`
- `PERSISTENT_INT8_SEMANTICS_STATUS`
- `FP_REFERENCE_STATUS`
- `STUDENT_32K_STATUS`
- `PROSPECTIVE_PRIMARY_STATUS`
- `DOCUMENT_LEVEL_VERDICT`
- `SCIENTIFIC_INTERPRETATION_STATUS`
- `TRAINING_AUTHORIZATION=NOT_AUTHORIZED`
- `FINAL_EXECUTION_STATUS`

最终原则：

**本轮不是为了跑出 P1 必胜的结果，而是为了在独立、预注册、真实 persistent INT8 的32K模型执行条件下，检验 P1 是否比原始 L7 更具有增量预测价值。**

结果好坏都必须完整报告，不得改变科研问题来迎合预期。
