# Reducer V3 specification

Prospective V3 removes the global interpolated-quantile hard gate because V2 established a statistical-contract mismatch. Primary metrics are runtime scale, PAPR, and QDQ relative L2. Primary tails are exact token-local p99, CVaR99, and max. The global multiplicative histogram is retained only for deterministic descriptive integer counts. Statistical unit is sample (N=60). One independent reducer state is produced per sample and aggregation follows the canonical manifest, never completion order.
