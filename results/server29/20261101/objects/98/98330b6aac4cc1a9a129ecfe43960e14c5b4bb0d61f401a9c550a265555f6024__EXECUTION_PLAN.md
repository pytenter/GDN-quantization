# LING_KDA_P1_L7_FUNCTIONAL_VALIDATION_V1

本轮只验证冻结的 P1 与 L7_TOTAL_ORIGINAL 排名，禁止训练、优化、AIME 和自由生成。

## 冻结设计

- pg19-test-860：P1 预测 H_to_L6_a50；L7 预测 H_to_L7_a25。
- pg19-test-5956：P1 预测 H_to_L6_a50；L7 预测 H_to_L7_a50。
- 复用 V4 数值源 persistent_engine_v1.py，SHA256=d448121735fd5ed7eff3a62689d359f17eca4b5467972ff69d299073a2b865c8。
- 同一个 Ling-3.0-tiny、原 token 文件、原 rotation 文件；不重选、不校准。
- teacher-forced，位置 t 消耗 token[t]，比较该步输出 logits，不移位。
- 每 token 18 层 INT8-R128 QDQ、逆旋转、原 cache 写回，下一步必须读取写回结果。
- FP32 cache 是原引擎的 dequantized INT8 数值载体；不得增加 FP shadow、reset 或降低量化频率。
- Primary：KL(softmax(FP)||softmax(student))，完整 157184 维词表，原 FP32 log_softmax/softmax 运算。
- 采样 t=8192+64*k，k=0..383。仅时间采样；词表不采样。
- 原 Python sum(values)/384 聚合；保留每点值、有限性、覆盖与采样身份。
- signed Delta=mean_KL(P1 rotation)-mean_KL(L7 rotation)。
- 数值分辨率沿用 V4 资格数据与预定算法：10*max(FP32 epsilon, 同 logits GPU32/CPU64 差异, 原 CPU reducer rounding)，在新结果之前冻结。

## 门禁顺序与停止

1. 新鲜校验冻结 model/rotation/token/source SHA，以及历史 STOP 未改变。
2. 验证 FP/student 配对身份、运行时与设备。
3. 保存 token 8192 边界的完整 native hybrid cache、位置与量化器／审计状态；比较不中断的 parent 与新进程 resumed。
4. 观察器只能读取；实际输出及 cache 要满足 no-mutation parity。
5. 原 INT8-R128、每步写回、next-kernel 消耗证明。
6. fresh-process exact repeatability，包括原 512-token 指纹与新 checkpoint continuation。
7. 完整词表 KL reducer 正确性，复用原资格证据并校验新采样覆盖与聚合。
8. 单卡实测／预测显存、CPU 内存、磁盘容量可行。

任一门禁失败，立即停止后续 GPU／科学运行，保留原证据并生成失败交付；未测值为 null／空白，禁止填零。历史 V4 的资源 STOP 不覆盖、不修复、不转写为 PASS。本轮新串行存储方案独立资格，不重新执行 V4 工程恢复。

## 串行资源方案

使用 physical GPU6，GPU-de53f243-b271-521c-d875-d96611ed8574，24GB RTX 3090；同 model、token 与 runtime。保持 V4 deterministic flags、BT16_W8、禁用 TF32。

FP 与四条 student 串行执行。GPU 同时只驻留一个 native full cache。FP 的 384 份完整 logits 存于 CPU／磁盘；不得保存全部 32768 dense logits。recurrent-state Secondary 需要的 reference 按冻结公式保存必要采样状态，不能影响 Primary。

每条 parent 从零运行到 8192，写完整 checkpoint，保持 QDQ 继续生成不中断的盲态 parity 证据。恢复必须使用全缓存，不能只恢复 recurrent state。只有所有八项门禁通过，才允许正式运行至 32768 和读取排名结果。

若真实 OOM，记录 physical resource stop；不得改变 horizon、metric 或冻结设计。
