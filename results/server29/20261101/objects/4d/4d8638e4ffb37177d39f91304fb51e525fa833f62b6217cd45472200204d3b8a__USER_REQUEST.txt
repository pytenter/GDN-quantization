2. 冻结科学问题和假设
==================================================

核心问题：

对于此前未用于本方法验证的真实长文档，在相同Hadamard Key-side Rotation、相同模型、相同真实逐token QDQ条件下，用Dual-M替换Canonical C128，是否能稳定降低32K full-model Future-KL？

比较三个条件：

N = FP_NATIVE
A = H_C128
D = H_DUAL_M

其中：
A保留原正式Canonical C128 column absmax量化规则。
D使用已经通过CPU和GPU parity的STEPQuant-inspired Dual-M：
- signed INT8 codes
- all8
- impact/readout weight = 1
- FP16 row scale + FP16 column scale
- zero FP16 pivots
- 原已资格的column least-squares与最终re-encode算法

不添加Dual-W。
不调整scale floor、clip policy、bitwidth。
不训练新的rotation。
不修改Hadamard矩阵。
不静默更换dtype、kernel、模型权重或QDQ次序。

严格要求每个token：

State -> INT8 quantize -> dequantize -> writeback

下一token消费当前token已经量化写回的状态。

禁止LeapQuant式延迟requantization、FP16/FP32高精度persistent buffer，以及只做一次离线fake quant的替代实现。

旧实现使用FP32 tensor携带QDQ后的状态，可以用于本轮科学复制；必须继续明确标记：

PERSISTENT_INT8_QDQ = QUALIFIED（通过验证后）
PHYSICAL_PACKED_INT8 = NOT_QUALIFIED

本轮不以实现真实packed INT8 runtime为目标。
