==================================================

这一阶段CPU-only，禁止GPU运行。

必须从真实源码确认：

4. Phase 0B：移植Dual-M到Ling/KDA
==================================================

优先复用Qwen已经通过CPU/GPU资格的Dual-M算法定义。

目标：
在KDA真实State矩阵上实现固定all-INT8的row×column separable scaling。

形式：

S_hat[i,j] = r[i] * c[j] * z[i,j]

其中：
z[i,j]为signed INT8整数code。
r[i]与c[j]使用FP16 scale元数据。

配置：
- all INT8
- 8 bits per state element
- importance/readout weight w_i = 1
- no FP16 pivots
- no mixed bitwidth
- no online learned parameters
- 使用已资格的column least-squares与最终re-encode
- 不引入Dual-W

必须按KDA实际Key-row/Value-column语义正确映射，不允许盲目复制Qwen的tensor维度、stride或scale索引。

禁止：
- 改为INT4/INT6
- FP16重要行保护
- delayed requantization
- 跨token未量化persistent state
- 跨token误差补偿buffer
- 静默改变scale floor与clipping策略

任何KDA特定scale安全适配，必须在科学运行之前根据数学与数值范围预注册，不允许看结果后调参。

CPU-only测试：
1. shape与axis测试
2. signed INT8 code范围
3. row/column FP16 scale正确性
4. zeros、outlier、ties、极端scale测试
5. encode/decode reference parity
6. 每token QDQ模拟
7. 128-step synthetic recurrence
8. fresh-process deterministic digest

如果官方STEPQuant参考实现及固定版本可访问，验证对应all8/ones/pivots0的行为；若无法访问，则明确记录独立参考的来源及证据边界，不能伪称官方exact parity。

必须明确：
FP32 tensor存放已经QDQ的state，不代表physical packed INT8。

9. Primary与Secondary科学指标
==================================================

实验前冻结以下估计目标。

Primary：

Delta_L6 =
K[L6,R128] - K[L6,DualM]

Delta_L6 > 0：
Dual-M在L6下产生更低Future-KL。

Key Secondary：

Delta_H =
K[H,R128] - K[H,DualM]

Interaction =
Delta_L6 - Delta_H

Interaction > 0：
Dual-M在L6条件下的绝对KL收益大于在H条件下的收益。

另需报告：

LearnedGain_R128 =
K[H,R128] - K[L6,R128]

LearnedGain_DualM =
K[H,DualM] - K[L6,DualM]

LearnedGain_DualM > 0：
在Dual-M量化器下L6比Hadamard具有更低KL。

注意：
Delta_L6>0只证明codec对L6的增量收益。

Interaction>0是正向交互的方向性证据，但若L6+DualM仍劣于H+DualM，不能宣称组合已经优于Hadamard方案。

严格区分：
1. Codec main effect
2. Learned rotation effect
3. Rotation × codec interaction
4. Actual best performing condition

对每个指标保留完整精度及算术分辨范围。

算术分辨须基于本轮实际reducer、FP32和独立CPU参考计算，不能直接套用Qwen或旧Ling某个固定阈值。

若差异处于合法算术分辨范围内：
NUMERICALLY_UNRESOLVED

FP32算术分辨不能被描述为full-model forward的完整数值误差上界。

A.

E.
Dual-M不改善L6，也不改善H：
说明Qwen的正向结果不能直接迁移到本次KDA条件，应暂停该codec组合路线。
