# A800 默认 dry-run 入口

本包只有一个入口：`source/a800_entry.py`。它读取同一份 `PAIRED_TRAINING_PREREGISTRATION.json`；默认仅用 Python 标准库验证配置、恢复原训练 AST 身份并打印计划，不导入 Torch/CUDA、加载模型、连接服务器或执行训练。

在本任务目录中，可审计的默认命令是：

```sh
python3 source/a800_entry.py
```

`--phase admission|teacher|train|validate|export --arm both|A|D` 只预览指定阶段。当前任何带 `--execute` 的调用都返回 `REFUSED` 和退出码 4；改写 JSON 的授权字段也不能启用未实现的完整模型执行路径。没有另一个绕过入口，没有自动租卡、完整训练、32K/AIME 或释放实例 API。

配置中的共同数值合同为 125 updates、每文档 1024 tokens/8 captures、H64、batch1、24 个共享头 Cayley 旋转共 195072 参数、Adam lr0.001/beta0.9/0.999/eps1e-8/clip1、Functional+0.1 State。A 与 D 的计划变量是 codec 与对应记录的 backward policy；其余共用一份配置。两臂只导出 final125，历史选中 update94 的 C6R 作为旧基线，不作为新产物选择规则。新 RepoBench 语料相对历史 WikiText 是两臂的共同变化，因此未来 G_adapt 的变化不能完全归于 codec。

`AUTHORITATIVE_AST_REUSE_AUDIT.json` 对权威原 engine 的 `train_document/evaluate/unified_teacher/cached` 等 6 个节点、原 core 的 recurrence patch/loss/teacher/student/detach 等 14 个节点、原 Cayley/C128 的 9 个节点给出原文件 SHA 和节点 AST SHA，并仅编译未执行。原 recurrence/kernel/loss body 没有改写。`codec_training_adapter.py` 中的局部算子资格不构成完整 9B 控制入口。

当前 `FULL_MODEL_RUNNER_IMPLEMENTATION = BLOCKED_UNCLOSED_CONTROL_DEPENDENCIES`。原 `c7_pipeline.py`、`formal_pipeline.py`、`fulldoc_common.py` 的控制依赖未恢复到可独立执行闭包；新模型加载、teacher 缓存、不可变权重检查与配对训练 I/O 尚未完成全链路资格。没有用空函数或局部算子替代这些依赖。因此这里交付的是可运输的计划/拒绝入口与真实恢复/导出函数，并非完整可运行的 A800 训练包。

`source/training_state_io.py` 提供真实的保存、恢复和导出函数。恢复限定为完整文档 optimizer step 后、cache 丢弃的边界；保存旋转、Adam、Python/Torch CPU RNG，以及已初始化 CUDA 的全部 RNG，附同臂 codec、配置/数据/teacher/source 身份、更新与暴露游标。它不声称恢复未保存的 BPTT 图。微测 checkpoint 明确标为 `MICRO_QUALIFICATION_ONLY`，导出函数拒绝把它变成正式旋转；正式 primary 导出要求 final125 和原 1e-4 正交阈值。

`A800_ENTRY_OFFLINE_TEST.json` 只证明默认 dry-run、配置对称性检查和执行拒绝；`CHECKPOINT_EXPORT_OFFLINE_INTERFACE_AUDIT.json` 只证明 schema/接口与错误拒绝。真实 tensor/Adam/RNG 恢复是否通过，须读取本轮独立 CPU 梯度资格记录；不能由这些标准库测试推断全模型恢复 PASS。

未来任何新授权任务仍须先准备完整环境：原 Python3.10.18/Torch2.5.1+cu121 与 pin 住的完整 Transformers 源码，不能只复制 modeling 文件；17 项模型/tokenizer 文件按 `ENVIRONMENT_PLAN.json` 的实际 SHA 独立核验。FLA 原实验未安装且未使用。新机器物理 A800 80GB、真实空闲显存、加载/forward/backward/teacher parity、两臂完整训练吞吐、内存稳定性和实际价格均需真实 admission；当前 `FULL_MODEL_A800_TRAINING = NOT_TESTED`。

当前成本独立 No-Go：按历史训练时间建立的中性场景为约 10.24 付费小时，超过拟议 8h；Dual-M 完整训练耗时与实际价格 UNKNOWN。不能承诺租 8h 足够，也不能只完成一臂后宣称配对有效。异常必须保留首失败并退出，不自动修补重跑。真实未来执行还需要完成有界停止、完整过程计费和文件封存后释放的控制闭包，本包不声称已经实现这些全模型行为。
