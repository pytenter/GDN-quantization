Original SHA-bound functions are extracted by AST; original model runners are never imported. H128 is Sylvester Hadamard normalized by sqrt(128); query and key are transformed on the Key axis. Native state `[B,H,K,V]` maps to `H.T @ S`; inversion is `H @ S_H`. C128 groups Key entries within each fixed Value column. Its official FP32 scale is `max(abs(X),dim=-2).clamp_min(1e-12)/127`; torch.round uses ties-to-even and signed levels -127 through 127. C64 is a new grouping condition, not an existing official runtime.

Original DualM fits row scales `safe_half(sqrt(mean_V(abs(X)).clamp_min(1e-20)))`, then initial column scales `safe_half(max_K(abs(X/r)/127))`. Initial codes are rounded from sequential `(X/r)/c`. One column least-squares fit uses `v=r*q`, numerator `sum_K(v*X)` and denominator `sum_K(v*v)`; zero denominator retains the initial column scale. A final re-encode recomputes codes from the original `(X/r)/c` with the fitted column scale. safe_half clamps to `[2^-24,65504]` and rounds to FP16. Reconstruction is `(r.float()*c.float())*q.float()`. T1/T2 must freeze these original fitted factors and encode the same normalized input, never re-quantize T0's reconstruction. This conditions the comparison on factors fitted for original codes; it is not joint optimization.
