22. CANDIDATE 2: FULL GDN PROPAGATION
============================================================

Core metric:

  J_PROP

Use the exact:

  propagate_zero_write

operator.

The goal is to estimate:

  sum over past injections
    of future propagated injection energy

while intentionally removing cross-time interference terms.

Use deterministic Rademacher shadow states.

For each recurrent layer and probe r:

  z_0^(r) = 0

At each step:

  z_{t+1}^(r)
      =
  propagate_zero_write(
      z_t^(r),
      record_t,
      R if condition-specific propagation is required
  )
  +
  xi[r,t+1,l] * eta_{t+1,l}

where:

  xi ∈ {-1,+1}

comes from a counter-based deterministic sign generator.

Sign schedule depends only on:

  experiment fixed seed
  document ID
  layer ID
  token index
  probe index

NOT on rotation.

Every rotation on the same document uses the same sign schedule.

============================================================
24. J_PROP
============================================================

For each layer/token:

  prop_energy_t,l
      =
  mean_r ||z_t,l^(r)||_F^2
  /
  (||S_fp_t,l||_F^2 + eps)

Define:

  J_PROP(R,T)
      =
  mean over recurrent layers
  and t ∈ [1024,T]
  of prop_energy_t,l

Interpretation:

In expectation over the random signs, this estimates the sum of squared
future-propagated injection contributions while removing cross-time
cross terms.

Do NOT claim:

  J_PROP == J_ACC

because J_ACC also contains cross-time alignment/cancellation terms.
