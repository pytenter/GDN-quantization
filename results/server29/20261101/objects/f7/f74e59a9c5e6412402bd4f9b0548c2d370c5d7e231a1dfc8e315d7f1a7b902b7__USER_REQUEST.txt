## 2. 冻结本次科学问题

本次主要问题：

**在冻结C6R learned rotation不变的条件下，仅将Canonical C128量化器替换为Dual-M，是否能够降低32K full-model Future-KL？**

次要问题：

**Dual-M对C6R的收益，是否不同于对Hadamard的收益？C6R+Dual-M是否优于Hadamard+Dual-M？**

原有Hadamard结果与新增C6R结果组成如下对照：

| Rotation | Canonical C128 | Dual-M |
|---|---|---|
| Hadamard | Historical H_C128 | Historical H_DUAL_M |
| C6R | New C6R_C128 | New C6R_DUAL_M |

共同评分参考为原五文档的FP_NATIVE。

科学对比必须区分：

- 同一GPU上新增的C6R两种codec对比。
- 新C6R与历史Hadamard之间可能存在跨GPU差异的对比。

不得将两个证据层级混为一谈。

### Primary

定义：

```text
K_C = KL(FP_NATIVE || C6R_C128)
K_D = KL(FP_NATIVE || C6R_DUAL_M)

Delta_C6R = K_C - K_D
```

`Delta_C6R > 0`表示Dual-M改善了冻结C6R系统的Future-KL。

这是本次唯一Primary。

### Key Secondary

历史Hadamard收益：

```text
Delta_H = K_H_C128 - K_H_DUAL_M
```

新旧旋转下的codec交互：

```text
Interaction = Delta_C6R - Delta_H
```

以及：

```text
LearnedGain_C128 =
  K_H_C128 - K_C6R_C128

LearnedGain_DualM =
  K_H_DUAL_M - K_C6R_DUAL_M
```

解释：

- Delta_C6R > 0：Dual-M对C6R有增量收益。
- LearnedGain_DualM > 0：C6R+Dual-M优于H+Dual-M。
- Interaction > 0：Dual-M在C6R下的绝对KL收益大于在H下的收益。

三者是不同的科学命题。

尤其不得把Delta_C6R正值直接解释为learned rotation与Dual-M已经具有正向交互。

## 10. 实验完成后的科学决策

根据结果明确分类。

### Case A：Dual-M改善C6R，且C6R+Dual-M优于H+Dual-M

这是最值得继续研究的组合结果。

说明在本次受测条件下，冻结learned rotation与Dual-M能够取得比Hadamard+Dual-M更好的绝对功能表现。

如果交互指标也稳定为正，值得另行开展独立同GPU、全新文档2×2确认。

### Case B：Dual-M改善C6R，但C6R+Dual-M仍不如H+Dual-M

说明Dual-M对learned rotation有增量价值，但不能证明learned方案已经成为最佳条件。

应进一步判断Interaction方向，以及C6R是否存在与Dual-M不匹配的旋转结构。

不立即训练C8。

### Case C：Dual-M改善C6R，但Interaction为负

说明codec收益可能在Hadamard条件下更大。

这并不表示Dual-M无效。

可能提示codec改善与learned rotation存在部分冗余，但机制尚需验证。

### Case D：Dual-M无法改善C6R

说明已有C6R不能直接从Dual-M中获益。

需判断是否是局部重建指标与长期功能表现脱节，或者现有旋转主要针对C128训练。

不得据此断言所有learned rotation与Dual-Axis均不互补。

### Case E：部分正向、部分负向

报告完整MIXED结果。

不得挑选有利文档进行宣称，也不自动增加样本或追加训练。

### Case F：GPU/数值/身份失败

如无法获得完整可比的科学证据，保留FAIL_CLOSED_STOP。

不能把工程失败解释为方法无效。

## 11. 后续新Rotation Loss研究：仅作为规划

本任务不训练C8。

只有当前实验显示出可解释的增量收益，才讨论将Dual-M直接纳入可学习旋转训练目标。

候选未来方向：

```text
Loss(R) =
    FunctionalLoss(R, DualM)
    + lambda * StateLoss(R, DualM)
```

但这只是候选Loss，不是已验证的方法。

未来必须独立研究：

- Dual-M下Functional Loss是否可优化。
- Learned rotation改善是否来自局部重建。
- 是否需要考虑长程scale feedback。
- 新训练目标能否预测32K Future-KL。
- 是否能进一步改善AIME26。

本次禁止根据结果自动开展上述任务。

## 14. 实际执行顺序

按照以下顺序：

**Phase 0 — CPU-only**

核验历史五文档资产、FP参考、C6R矩阵和源码身份，明确跨GPU协议边界，并冻结本任务科学分析。

核验SHA、历史资产不变、GPU释放和最终科学状态。

本任务最终要回答的核心问题只有一个：

**在Qwen/GDN的严格persistent INT8 recurrent-state量化中，已经训练好的C6R正交旋转能否从Dual-Axis codec中获得真实长期功能收益？**

只有这个问题得到合法证据后，才决定是否值得继续研究learned rotation与Dual-Axis之间的交互机制及新的训练目标。
