==================================================
五、预先冻结 surrogate 的定义
==================================================

PRIMARY：

S1 = mean(relu(log(s_student/s_clean))^2)

其中 s_student 是真实 persistent-QDQ 学生状态
产生的 adaptive scale。

s_clean 是同 rotation、同 token、同 layer/group、
同驱动下配对 clean-FP state 的 formal scale。

必须按实际量化器的 clamp_min 规则处理正数 scale。

禁止混用不同旋转的 clean scale。
禁止用不同模型运行条件的旧 FP scale 代替。

SECONDARY：

s_cap = min(s_student,s_clean)

S2 = mean(
  ||QDQ(u;s_student)-QDQ(u;s_cap)||^2
  / (||u||^2 + epsilon)
)

u 为同一份 student pre-QDQ state。

S2 只测一步局部 counterfactual grid distortion。
不可让 capped 分支写回 parent recurrent state。
不得把 S2 称为完整长程因果收益。

epsilon / aggregation / group weighting
必须在测量前冻结并记录。

NEGATIVE / SPECIFICITY CONTROLS：

D1 = mean(relu(-r)^2)
D2 = mean(r^2)
r = log(s_student/s_clean)

BASELINES：

B0 = original C5 State relative-MSE
B1 = original C6 Functional relative-MSE
B2 = original C6 Functional + 0.1 State

基线必须使用仓库原数学定义和统计归约方式。
不可用近似实现替代 original loss。

全部 short metrics 在相同 documents、
capture positions、rotations、FP pairing、
quantizer 和 token windows 下测量。

不得根据测量结果临时选择 aggregation。
