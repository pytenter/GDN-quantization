# Qwen3.5 GDN/KDA Quantization Sensitivity

This directory contains non-invasive experiment entry points for Qwen3.5-9B.
The scripts do not modify model source code. They load the HuggingFace model with
`trust_remote_code=True` and use runtime hooks or cache inspection where possible.

Run order:

```bash
python3 experiments/qwen35_gdn_quant/inspect_arch.py
python3 experiments/qwen35_gdn_quant/fp16_baseline.py
python3 experiments/qwen35_gdn_quant/quant_weight.py --mode w8
python3 experiments/qwen35_gdn_quant/quant_weight.py --mode w4
python3 experiments/qwen35_gdn_quant/quant_activation.py --bits 8
python3 experiments/qwen35_gdn_quant/quant_activation.py --bits 4
python3 experiments/qwen35_gdn_quant/quant_state.py --bits 8
python3 experiments/qwen35_gdn_quant/quant_state.py --bits 4
python3 experiments/qwen35_gdn_quant/quant_state.py --bits 2
python3 experiments/qwen35_gdn_quant/analyze_error.py
```

The current server Python does not include `torch`, `transformers`, `numpy`, or
`matplotlib`, so only `inspect_arch.py` and static report generation can run here
without changing the environment.
