## Exact definition and alignment

`local_output` (trainer lines 272–276) applies the frozen layer's real gated `o_norm` to native KDA core output and captured FP dynamic gate, then reshapes heads and applies `o_proj`. The target is captured `out_proj_output` after that projection, not logits, K3, pre-projection core error, or generic MSE.

Functional: `sum((student.float()-teacher.float())²) / clamp_min(sum(teacher.float()²), 1e-12)` for one token/layer, then equal average over 18 layers and tokens. The head contributions are mixed by the real output projection, not averaged as independent head losses.

State: reduce squared errors over K/V separately for each batch/head; divide by that head's FP state energy clamped at `1e-12`; mean over batch/heads, then equal average over 18 layers/tokens. This is not global relative-MSE and not raw B0 MSE.

Total: `Functional + 0.1 × State`. No scaling/threshold fitted to correlations.

In `rollout_chunk` (299–363), functional output is the current fused recurrence readout recovered from the rotated value basis, followed by norm/gate/projection. It is not recomputed from the current post-QDQ state. State loss uses the current post-QDQ dequantized state recovered to native coordinates. Current-token output reflects prior writebacks; current post-QDQ state affects the next token.

Original training uses shared FP q/k/v/beta/decay/gates for teacher/local student, QDQ before each persistent writeback, BF16 quantization boundary and BF16 dequant, numerical state continuity, 512-token WikiText2 traces. `init_states` quantizes the initial FP teacher state in the rotated basis. The model is frozen. Layer rotations are shared over heads.

Collection (119–229) prefills the native FP teacher cache, captures each subsequent consecutive token, and stores q/k/v, dynamic gate and projected target as BF16, beta/log_decay as FP32. Attention masks are all ones; no loss-specific token mask or extra ratio normalization appears. No new training or trace collection is executed here.

Training (642–773) samples one of 64 documents per optimizer step with seed 0, maintains numerical student state through the 512-token sequence, backpropagates each H128 chunk with length/512 weighting, and detaches teacher/student graphs at chunk boundaries without resetting state. Validation (586–617) weights losses by tokens, equivalent to equal documents for equal 512-token lengths. Original protocol: Adam, lr=.003, no weight decay, global gradient clip 1, 100 steps, validation every 10 steps. These describe history only; this run never invokes `phase_train`, backward, or optimizer updates.

## Historical optimization evidence, not a causal explanation

Original training optimized Total but selected by `validation.primary = Functional`. Across the 11 recorded validation evaluations, Functional, State and Total decreased; both minimum Functional and minimum Total occur at step 100, the selected checkpoint. Functional fell from 0.00312087667407468 at step 1 to 0.00231130659813061 at step 100. Thus the different selection criterion did **not** select a different checkpoint among recorded candidates. It cannot currently explain the weaker external endpoint.

STE bias, H128 truncation, data-distribution mismatch, state weighting, insufficient optimization and local-objective/reasoning mismatch remain hypotheses. There is no P1/L7 ranking or gradient-equivalence result yet. Optimization failures cannot be inferred from static code alone.
