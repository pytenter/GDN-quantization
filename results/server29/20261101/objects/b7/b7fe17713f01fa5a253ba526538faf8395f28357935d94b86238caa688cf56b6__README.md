This is an unbound engineering candidate outside frozen source543. It is a new format proposal, not an authorized production repair or an unchanged R2/R3 result. It has not run on a GPU or model. The current scale-repair experiment remains a true STOP: zero new formal completions plus three original completions.

`ORIGINAL_FROZEN_QUANTIZER.py` is an exact copy of the immutable repaired quantizer. `pace_quantizer_candidate.py` preserves its packing, zero-inclusive affine interval, stored-mantissa rounding, integer zero point and old accepted mapping. Initial positive finite FP16 casts use exponent0, including any actually accepted rounding-band inputs. Ordinary groups allocate no exponent tensor when the whole packed part needs no extension.

Recurrent-state encoding enables optional exponents. Generic `PackedAffineGroups.from_tensor` keeps `allow_scale_exponents=False` by default, so existing INT4 buffered keys retain their original codec and memory. Only an initial invalid FP16 scale triggers the exponent path. A dense actual INT8 exponent tensor is then allocated for that INT4 or INT8 state part, with zero entries for ordinary groups. The frexp chooser includes a bounded correction for overflow midpoints at later binades, such as131040/2=65520. Exponents must be0..127. Both the reconstructed scale and actual decoded FP32 values must remain finite. There is no scale clipping, FP32 scale field, rotation, dense persistent state or numerical-stability guarantee.
