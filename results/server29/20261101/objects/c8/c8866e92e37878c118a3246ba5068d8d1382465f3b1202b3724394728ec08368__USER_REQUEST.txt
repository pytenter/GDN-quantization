6. P3：S1/S2 Observer资格
==================================================

只有数值闭环PASS后执行。

正式INT8 quantizer身份保持不变：

zero_point=0
qrange=[-127,127]
rounding=torch.round
scale=amax(dim=-2,keepdim=True).clamp_min(1e-12)/127

S1：

r=log(s_student/s_clean)

S1=mean(relu(r)^2)

S2：

s_cap=min(s_student,s_clean)

S2=mean(
  ||QDQ(u;s_student)-QDQ(u;s_cap)||²
  /(||u||²+1e-12)
)

u必须是同一个student pre-QDQ state。

S2仅为观察分支：
不得写回recurrent state。

D1=mean(relu(-r)^2)
D2=mean(r²)

明确冻结aggregation axes、dtype、
group/layer weighting、finite规则。

必须完成observer OFF/ON parity：

- 主QDQ codes
- recurrent state
- logits
- next-token consumption
- cache writeback

必须满足事前冻结的无副作用判据。

关闭observer和打开observer
不能导致主科学轨迹发生未解释的差异。
