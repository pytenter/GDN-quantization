# 20. Exact error decomposition

维护：

```text
S_t^FP

S_t^Q,R
```

FP：

```text
S_{t+1}^FP =
F_t(S_t^FP, u_t)
```

persistent INT8：

```text
S_{t+1}^Q,R =
Q_t^R(S_t^Q,R, u_t)
```

actual accumulated error：

```text
E_{t+1}
=
S_{t+1}^Q,R
-
S_{t+1}^FP
```

history propagation：

```text
H_{t+1}
=
F_t(S_t^Q,R, u_t)
-
F_t(S_t^FP, u_t)
```

path-conditioned injection：

```text
I_{t+1}^PATH
=
Q_t^R(S_t^Q,R, u_t)
-
F_t(S_t^Q,R, u_t)
```

必须满足：

```text
E = H + I_PATH
```

# 21. Clean-state injection

# 40. Most important interpretation

这个实验不是为了证明：

```text
J_PROP > J_INJ
```

也不是为了恢复旧 12-condition experiment。

它要回答更基础的问题：

```text
为什么两个 INT8 rotation
在 instantaneous quantization error 相近或更小时，
长期 recurrent-state error
仍然可能出现完全不同的行为？
```

通过：

```text
ACCUMULATED ERROR
        =
HISTORICAL ERROR PROPAGATION
        +
CURRENT PATH-CONDITIONED INJECTION
```

以及 energy-space：

```text
ACC ENERGY
=
HISTORY ENERGY
+
INJECTION ENERGY
+
ALIGNMENT / CANCELLATION
```

来直接拆解。

优先得到一个可靠、可复现、低工程复杂度的机制结论。

不要为了恢复旧 protocol 而增加不必要复杂度。
