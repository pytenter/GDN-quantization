# Runtime and memory estimate

## Controlled reducer plane

The final accelerated smoke measured 0.3969352484 token/s on one RTX 3090.
For 1,854,451 frozen tokens this projects to:

- 4,671,923 s / 1,297.76 GPU-hours;
- ideal four-GPU wall time 1,167,981 s = 324.44 h = 13.52 days.

The scalar sidecar and Parquet writer are budgeted at 10–20% overhead. Planning
range: 1,427.5–1,557.3 GPU-hours, or 14.87–16.22 days on four GPUs.

## Recurrent/function plane

The prior formal three-row replay completed four shards in 13,193 s, 13,788 s,
14,581 s, and 12,253 s. That is 14.95 GPU-hours and 4.05 h maximum shard wall
time per bundle. Two sequential bundles project to about 29.90 GPU-hours and
8.10 h wall time. Budget 10 h for learned-rotation and I/O variance.

## End-to-end planning envelope

- GPU-hours: approximately 1,457–1,587.
- Four-GPU wall time: approximately 15.2–16.7 days.
- CPU finalization/hashing: 2–6 h, mostly after GPU completion.

The controlled reducer dominates. This estimate is intentionally based on the
measured exact accelerated path, not the much faster but scientifically
insufficient historical descriptive capture.

## Memory

- Exact controlled smoke: 16.940 GiB allocated, 16.964 GiB reserved.
- Prior three-row recurrent maximum: 22,113 MiB.
- Sidecar scalar buffers: budget <=256 MiB GPU per active sample.
- Parquet row groups and queues: budget <=8 GiB host RAM per worker.

Five simultaneous recurrent rows are forbidden. Execute the two fixed
three-row bundles sequentially and require a longest-prefix resource smoke
before Full60 authorization.
