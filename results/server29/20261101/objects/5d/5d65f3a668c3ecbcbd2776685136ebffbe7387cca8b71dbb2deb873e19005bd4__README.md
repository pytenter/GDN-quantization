# PACE48 LQUnroll dP32 吞吐专项

这是独立的吞吐测试目录。只比较同一 Mixed INT4/INT8 Direct Read 的 dP8、dP16、dP32；不执行 AIME 自由生成、评分、Pure INT4、训练或后续周期。

唯一实际运行状态以 `runtime`、`RESULT.json` 和真实 owning receipts 为准。`cpu_tests/CPU_FIXTURES_ONLY_*` 中的数据仅用于启动前 CPU 报告链路测试，不是吞吐测量，不进入根目录的科学结果 CSV。

源码依据、原字节比较和唯一的 period 参数准入变更见 `SOURCE_IDENTITY.json`。原 dP8/dP16 正式目录保持只读。所有配置均在同一张确认空闲的 RTX3090 上以单 UUID CVD、TP1 运行，新的编译缓存位于本任务独立路径。

最终报告为 `THROUGHPUT_COMPARISON.md`、`NUMERICAL_VALIDATION.md`、`KERNEL_LATENCY_REPORT.md`、`MEMORY_ACCOUNTING.json`、`BENCHMARK_RAW.csv` 和 `EXECUTION_LOG.md`。没有实际性能测量时不伪造数字或创建空科学 CSV。主 `MANIFEST.sha256` 只在全部 owning 链真正退出后，由独立 CPU reader 封存。
