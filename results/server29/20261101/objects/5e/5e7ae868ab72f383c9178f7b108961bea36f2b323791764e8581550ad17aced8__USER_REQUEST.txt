==================================================
七、正式S1/S2定义
==================================================

对同rotation、同token、同layer、
同quantizer group的paired scales：

r = log(s_student / s_clean)

PRIMARY：

S1 = mean(relu(r)^2)

SECONDARY：

s_cap = min(s_student,s_clean)

S2 =
mean(
  ||QDQ(u;s_student)-QDQ(u;s_cap)||²
  /
  (||u||²+epsilon)
)

u必须是同一份student pre-QDQ state。

S2观察分支：

- 不得写回recurrent state
- 不得改变主轨迹
- 不得修改quantizer
- 不得触发额外模型状态变化

正式quantizer：

zero_point=0
qrange=[-127,127]
rounding=torch.round
scale=amax(...).clamp_min(1e-12)/127

其完整维度和归约使用原正式实现。

S1按token、layer及scale元素等权汇总，
先冻结确切维度与mask，避免层规模偏置。

S2先进行同layer的relative normalization，
再按layer/token等权汇总。

epsilon采用经审计的原helper数值约定；
如果没有直接适用的原约定，
在首个科学score前固定为1e-12，
并单独记录该新设计选择。

同时记录S2两套网格的clipping/saturation
比例，避免将网格差异误解为必然的损伤改善。

控制项：

D1 = mean(relu(-r)^2)
D2 = mean(r²)

基线：

B0 = original C5 State relative-MSE

B1 = original C6 local Functional relative-MSE

B2 = B1 + 0.1*B0

B0必须使用原每head矩阵relative-MSE，
分母clamp_min(1e-12)，再按层汇总。

B1必须使用真正的out_proj output
与matched teacher output，
global relative-MSE后再按层汇总。

不能用drive内q/k/v/g/beta或out_proj权重
构造近似functional loss来冒充B1。

所有指标须由正式helper和匹配forward计算。
