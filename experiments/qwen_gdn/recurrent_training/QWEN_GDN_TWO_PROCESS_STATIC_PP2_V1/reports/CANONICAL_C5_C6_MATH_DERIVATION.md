# Frozen C5/C6 mathematics and PP2 decomposition

For each capture point and GDN layer `l`, `relative_state_mse` (V1 lines 121–130) applies the original Hadamard `H` and Cayley correction `Delta_l` to the *pre-update student recurrent state*, obtaining `recover_state(student_prev_l, Delta_l, H)`. It computes `mean_{batch,head} [ sum_{K,V}(recovered-teacher_prev_l)^2 / max(sum_{K,V} teacher_prev_l^2, 1e-12) ]`. The teacher target is detached. There are exactly 24 GDN layers, so `state = sum_l state_loss_l / 24` (V1 lines 332–342); `C5 = state`. Rank0's 12 losses and rank1's 12 losses must **both divide by 24**. Dividing by 12 on either stage would double the combined objective.

The out-projection forward hook stores detached teacher outputs or student functional errors (V1 lines 279–291). `CAYLEY.relative_mse` (rotation source lines 173–176) computes `sum_all (out_student.float-out_teacher.float)^2 / max(sum_all out_teacher.float^2,1e-12)`. `functional = sum_l functional_loss_l / 24`; `C6 = functional + 0.1*state` (V1 lines 332–342). Both local terms can be decomposed using the same global denominator; the scalar C6 loss has no separate cross-stage dependency beyond the hidden activation chain and each stage's own local hook captures.

Formal V1 document training freezes eight sampled capture positions per document. At every capture, it appends the selected `C5` or `C6` divided by **8**, sums losses within each BPTT segment, calls backward at the segment boundary, then performs one Adam update after the entire document (V1 lines 785–857). The historical feasibility H1 diagnostic instead uses the first 32 non-AIME TRAIN tokens and one capture at token index 31, with no eight-target divisor. This task uses that frozen H1 diagnostic for parity, not formal training.

Teacher targets: `collect_teacher_targets` (V1 lines 377–398) advances a complete, unrotated 32-block teacher in no-grad mode through each prefix and captures at the selected token. The teacher cache is continuous across prefixes; pre-update FP32 GDN state and out-projection output targets are detached to CPU. `install_teacher_target` copies those local targets back to the student device before capture. The teacher runs canonical Qwen operators; in `patch.mode='teacher'`, `_wrap` forwards to the original GDN function without rotation/QDQ. The student uses the same original GDN core after Key-side Hadamard+Cayley transformation, then INT8-C128 QDQ of the updated FP32 state and differentiable cache writeback (V1 lines 239–277, 294–329, 356–405).

`detach_cache` (V1 lines 153–185) detaches recurrent states, convolution states and key/value caches, trims convolution history to the kernel window, and retains `record_past=True`. PP2 must perform this on both stage-local caches after the same global token positions `(i+1)%H==0`; the numerical recurrence continues across a boundary while the gradient graph does not. The post-block-15 hidden tensor requires explicit cross-process gradient handoff; `dist.send/recv` does not create autograd edges.
