# Prospective horizon amendment proposal

H=32 is not sustained resource-feasible on the audited 24GB implementation. A future, separately approved protocol amendment may test H=16 and then H=8, using resource feasibility and numerical stability only. Each candidate would need 20–30 optimizer updates including validation, with fresh recurrent writeback, provenance, gradient, BPTT boundary, and memory lifetime gates. No candidate was run in this audit. Formal C5/C6 and AIME remain stopped.
